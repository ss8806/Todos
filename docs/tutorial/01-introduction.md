## フロントエンド

### Next.js 16 (App Router)

**役割**: Reactフレームワーク

**選定理由**:
- **App Router**: 従来のPages Routerに比べ、Server Componentsによるパフォーマンス最適化が可能
- **フルスタック機能**: API Routes、ミドルウェア、画像最適化などが標準搭載
- **TypeScriptネイティブ**: 型安全性を確保しやすい

### TypeScript

**役割**: 型付きJavaScript

**選定理由**:
- **型安全性**: コンパイル時にエラーを検出し、バグを減らせる
- **IDEサポート**: 自動補完とリファクタリングが強力
- **スキーマ共有**: バックエンドのPydanticスキーマと型の整合性を保ちやすい

### Tailwind CSS

**役割**: ユーティリティファーストCSSフレームワーク

**選定理由**:
- **開発速度**: クラス名を考える必要がなく、HTMLに直接スタイルを記述
- **デザイン一貫性**: プリセットされたデザインシステム（色、間隔、タイポグラフィ）
- **ビルド最適化**: 未使用のスタイルが自動で削除され、軽量なCSSを出力

### shadcn/ui

**役割**: 再利用可能なUIコンポーネントライブラリ

**選定理由**:
- **コピー&ペースト方式**: npmパッケージとしてではなく、実際のコードをプロジェクトに配置できるためカスタマイズが自由
- **Tailwind CSS連携**: Tailwindと完全に統合されている
- **アクセシビリティ**: WAI-ARIA準拠のコンポーネント
- **Radix UIベース**: 堅牢なヘッドレスUIライブラリを基盤としている

### TanStack React Query

**役割**: サーバー状態管理ライブラリ

**選定理由**:
- **キャッシング**: APIレスポンスを自動でキャッシュし、再取得を最適化
- **楽観的更新**: UIを即座に更新し、バックグラウンドでAPIと同期
- **エラーハンドリング**: エラー時の自動リトライ、ローディング状態管理
- **データ同期**: ミューテーション後の自動再検証

### React Hook Form + Zod

**役割**: フォーム管理とバリデーション

**選定理由**:
- **パフォーマンス**: 非制御コンポーネントによる不要な再レンダリングを防止
- **型安全性**: ZodスキーマからTypeScriptの型を自動生成
- **軽量**: 小さなbundleサイズ
- **エラーメッセージ**: 日本語化しやすい

## バックエンド

### FastAPI

**役割**: Python製の高速なWebフレームワーク

**選定理由**:
- **非同期サポート**: `async`/`await`による高パフォーマンスなI/O処理
- **自動ドキュメント**: OpenAPI/Swaggerドキュメントをコードから自動生成
- **型ヒント**: Pythonの型ヒントから自動でバリデーションとシリアライゼーション
- **エコシステム**: SQLModel、python-joseなどの連携が充実

### SQLModel

**役割**: ORM（オブジェクト関係マッピング）

**選定理由**:
- **Pydantic統合**: データベースモデルとAPIスキーマのコード重複を削減
- **SQLAlchemyベース**: 成熟したORMの機能をそのまま利用可能
- **非同期対応**: `AsyncSession`による非同期DBアクセス

### PostgreSQL + asyncpg

**役割**: リレーショナルデータベース

**選定理由**:
- **堅牢性**: 本番環境で実績のあるオープンソースDB
- **非同期ドライバ**: `asyncpg`による高性能な非同期接続
- **JSONサポート**: 必要に応じて半構造化データも保存可能
- **Alembic連携**: マイグレーションツールとの連携が標準的

### JWT (python-jose)

**役割**: ステートレス認証

**選定理由**:
- **スケーラビリティ**: サーバー側にセッションを保持する必要がない
- **標準的**: OAuth2 / OpenID Connectとの親和性が高い
- **FastAPI統合**: `OAuth2PasswordBearer`との連携が簡単

### SlowAPI

**役割**: レート制限

**選定理由**:
- **シンプル**: デコレータ1つでエンドポイントにレート制限を適用
- **柔軟性**: エンドポイントごとに異なる制限を設定可能
- **セキュリティ**: ブルートフォース攻撃やAPI乱用を防止

## 開発ツールとインフラ

### uv

**役割**: Pythonパッケージマネージャー兼実行環境

**選定理由**:
- **高速**: pipに比べて圧倒的に速い依存関係の解決とインストール
- **ロックファイル**: `uv.lock`による再現性のあるビルド
- **統合**: `pyproject.toml`ベースのモダンなPythonプロジェクト管理

### Bun

**役割**: JavaScriptランタイム兼パッケージマネージャー

**選定理由**:
- **高速**: npm/yarnに比べて高速なパッケージインストール
- **Next.js対応**: Next.jsの開発サーバー実行が可能
- **統合**: ランタイム、パッケージマネージャー、バンドラーが一体

### Docker Compose

**役割**: 開発環境のコンテナ化

**選定理由**:
- **一貫性**: チーム全体で同じ環境を共有
- **簡単起動**: `docker compose up`でDBなどの依存サービスを即座に起動
- **分離**: ホストマシンを汚染しない

### just

**役割**: コマンドランナー

**選定理由**:
- **シンプル**: Makefileよりシンプルな構文
- **クロスプラットフォーム**: Windows/Mac/Linuxで同じように動作
- **可読性**: 開発用コマンドを集約し、チーム内で共有しやすい
