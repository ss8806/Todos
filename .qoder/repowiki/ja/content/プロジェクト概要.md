## 導入
本プロジェクトは、モダンなツールチェーン（Bun、uv、Jujutsu）を活用したTodoアプリケーションです。FastAPI（バックエンド）とNext.js（フロントエンド）をベースに、JWT認証、リアルタイム更新、レート制限、構造化ログ、E2Eテストを備えたポートフォリオ用途の教育型フルスタックアプリケーションです。

主な目的と目標：
- 現代的な開発手法とツールの実践例を示す
- 認証・Todo管理機能を網羅的に実装し、動作を検証する
- Dockerによるコンテナ化、GitHub ActionsによるCI/CDを実装し、運用基盤を整備する
- 学習者にも理解しやすい設計とドキュメントを提供する

### 認証フロー（JWT）
認証プロセスの流れは以下の通りです。登録→トークン取得→保護ルートへのアクセス（Bearer認証）。

```mermaid
sequenceDiagram
participant U as "ユーザー"
participant FE as "フロントエンド"
participant BE as "FastAPI"
participant DB as "PostgreSQL"
U->>FE : "登録フォーム入力"
FE->>BE : "POST /api/v1/auth/register"
BE->>DB : "ユーザー作成パスワードハッシュ"
DB-->>BE : "登録成功"
BE-->>FE : "登録完了"
U->>FE : "ログインフォーム入力"
FE->>BE : "POST /api/v1/auth/token"
BE->>BE : "JWTトークン発行"
BE-->>FE : "access_token"
U->>FE : "Todo一覧表示"
FE->>BE : "GET /api/v1/todos/ (Authorization : Bearer)"
BE->>DB : "認証・クエリ実行"
DB-->>BE : "Todoリスト"
BE-->>FE : "レスポンス"
```
